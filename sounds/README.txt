Atlas sounds

Leave this folder empty and Atlas plays its built-in sound: the Atlas theme on the world map,
and real field recordings streamed from Wikimedia Commons for each place.

To use your own audio for a soundscape, put a loopable file here (mp3 or m4a work on iPhone)
and name it in the LOCAL list at the top of sound.js, for example:

    jungle: 'sounds/jungle.mp3',

Profiles: space (the world map theme), jungle, ocean, rainforest, city, metropolis, desert,
mountains, temple. A local file always wins over the streamed recording.
