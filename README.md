# Atlas

An interactive world atlas: tap a country, open a place, and get full-screen photographs and its own soundscape.

Live at https://ryanskyhighmanagement.github.io/atlas/

Plain HTML, CSS and JavaScript with Leaflet. No build step.

Credits: map tiles by Esri (with HERE, Garmin and OpenStreetMap contributors); country borders from Natural Earth via world-atlas; photographs and sound recordings from Wikimedia Commons, credited inside the app.
